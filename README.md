## 🚀 COMPLETE UNLIMITED COMMAND MANUAL

### I. ECONOMY & BUSINESS SYSTEM
Build a global corporate conglomerate, trade equities, and generate passive revenue streams.

* `/business create <name>` — Establish a new business entity under your profile.
* `/business manage` — View business metrics, upgrade infrastructure, and collect hourly revenue.
* `/business invest <amount>` — Inject capital into core industrial sectors to increase income multipliers.
* `/hourly` — Claim guaranteed hourly yields generated by your active enterprises.
* `/stocks market` — Display real-time valuation charts for active equities.
* `/stocks trade buy <symbol> <shares>` — Execute immediate market buy orders.
* `/stocks trade sell <symbol> <shares>` — Execute market sell orders and liquidate holdings.
* `/portfolio` — Display your full asset allocation, business valuation, and liquid reserves.

---

### II. LEVELING & LEADERBOARD SYSTEM
Drive chat activity with automated experience point distribution and role rewards.

* `/level` (or `/rank`) — Generate your official statistics card showing XP, current level, and rank progression.
* `/leaderboard` — Display the server-wide top 20 rankings sorted by message activity and XP.
* *Passive XP Engine:* Automatically credits experience points for unique channel messages with built-in anti-spam cooldowns.
* *Custom Role Mapping:* Allows server administrators to map custom role unlocks to specific level milestones.

---

### III. ARCADE & MINIGAME ENGINE
Run interactive games directly inside text channels without external websites.

* `/minigame arcade` — Launch the main arcade interactive dashboard.
* `/chess invite <user>` — Send an interactive chess match challenge to another server member.
* `/words` — Start a round of competitive word identification and trivia.
* `/minigame daily` — Complete daily micro-challenges to claim bonus economy credits.

---

### IV. UTILITY, TRACKING & SUPPORT
Streamline administrative tasks and server member integration.

* `/origin <member>` — Query the recorded origin data for a specified server member.
* `/setorigin <member> <text>` — Update or overwrite origin tracking attributes for member logs.
* `/ticket open` — Initialize a private support channel between a user and server staff.
* `/ping` — Measure network latency, WebSocket heartbeats, and API response performance.
* `/info` — Display system health, host statistics, version history, and active session duration.
